## Snapshot status

The repository is archived. Although the original README lists a broad planned taxonomy, only **Accessibility** contains resources in this fixed snapshot.

Availability, price, license, output format, editability, attribution requirements, account requirements, and accessibility of linked services have not been revalidated. “Free” in the title is therefore not a promise that every destination remains cost-free or grants rights for every use.

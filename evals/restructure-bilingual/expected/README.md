# Paperplane

Paperplane is a web-app fixture with a local development and production-build path.

> Current fixture version: `2.0.0`.

## Local development

```bash
npm run dev
```

The development server binds to `127.0.0.1` according to `package.json`.

## Build

```bash
npm run build
```

See [Migration notes](docs/migration.md) for the version 2.0.0 script change.
